# Salvador Microplastics Analysis
This repository contains the R script and supporting data used for the statistical analysis of the study *Occurrence and Morphological Characterization of Putative Microplastic Particles in Marine Organisms from the Coastal Region of Salvador, Bahia, Brazil*.

The code was developed to organize the statistical workflow used in the manuscript, from data checking and preparation to statistical tests, figure generation, and export of the main results.

## About the project
The study investigated the occurrence and morphological characteristics of putative microplastic particles in marine organisms collected from the coastal region of Salvador, Bahia, Brazil.

For the statistical analysis, particle counts were compared among three trophic levels and between two analytical fractions obtained during sample processing: the floating and decanted fractions.

The R workflow includes:

* data import and basic consistency checks;
* data preparation and classification of trophic levels;
* descriptive statistics;
* Kruskal–Wallis tests;
* Bonferroni-adjusted Dunn's post-hoc test for the floating fraction;
* generation of the particle-count boxplot;
* export of the statistical results as CSV and XLSX files.

The particles are referred to as **putative microplastics** because their identification was based on morphological and visual characteristics. No spectroscopic or chemical analysis was performed to confirm polymer composition.

Morphology and color data are also included in the repository. These data were used for descriptive analyses and are not part of the statistical workflow implemented in the R script.

## Running the analysis
The analysis was developed in **R 4.6.1** and can be run through RStudio.

Required packages:

```r
dplyr
tidyr
ggplot2
FSA
openxlsx
here
```

To run the workflow:

1. Clone or download the repository.
2. Open `salvador-microplastics-analysis.Rproj` in RStudio.
3. Open `scripts/statistical_analysis.R`.
4. Install the required packages if necessary.
5. Run the script.

The project uses the `here` package to work with paths relative to the project folder. This means that the file paths do not need to be changed when the project is moved to another computer.

The script also creates the `results/figures` and `results/tables` folders when necessary.

## A note about the data
The particle counts used in the statistical analysis correspond to the particles observed in six microscope-slide drops per specimen.

These values represent the observations used in the analysis and should not be interpreted as total particle burden, particle concentration per gram of tissue, or an estimate of the total number of particles present in each organism.

For the complete description of sampling, laboratory procedures, particle characterization, statistical methods, and interpretation of the results, please refer to the manuscript.
